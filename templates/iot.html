Hardware integration plan

  1. Use an ESP32 development board as the machine-side controller.
  2. Use an approved, isolated, non-invasive sensing arrangement selected with qualified supervision.
  3. ESP32 reads a safe low-voltage sensor output and sends a status payload over Wi-Fi.
  4. Flask receives the payload through a protected API or MQTT broker and updates the machine record.
  5. The web dashboard refreshes and displays the latest status and timestamp.

Safety: Students must not open or modify mains wiring or connect a DIY circuit directly to a washing machine. Hardware installation must be designed and checked by a qualified supervisor.
